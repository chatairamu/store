# List of Pending/Missed Features from Original Scope

This document outlines the features from the original project description that have not yet been fully implemented. The core foundation for many of these exists in the database schema and application structure.

## I. Core Systems

- **Reviews and Ratings System**:
  - UI and API for customers to leave reviews/ratings on products and vendors.
  - A moderation system for admins to approve/reject reviews.

- **Wishlist Functionality**:
  - UI and API for users to add/remove products from their personal wishlist.

- **Live Order Tracking**:
  - Integration with Leaflet.js to show a live map of the delivery partner's location.
  - This would require an API endpoint for the delivery partner's app to periodically send its coordinates.

## II. Advanced Logic & Customization

- **Full GST/Tax Calculation**:
  - The current system has a placeholder for GST. A full implementation would read the `gst_slab_id` from each product and calculate taxes accurately based on the `gst_slabs` table.

- **Advanced Vendor Settings**:
  - Per-vendor delivery charge logic (e.g., distance-based, per-product).
  - Vendor commission calculation (fixed or percentage) to be reflected in earnings reports.
  - Per-vendor minimum cart value enforcement.

- **Advanced Product Settings**:
  - Per-product overrides for delivery and packaging charges.
  - Product tagging system for better filtering and search.
  - Logic for `special_price` and `discount_type` fields.

- **Advanced Cart & Checkout**:
  - Full AJAX-based cart page for real-time updates without page reloads.
  - Integration with Google Maps API for address selection and validation.

## III. Security

- **CSRF Protection**:
  - Implementation of CSRF tokens, especially for forms submitted from the views, to prevent cross-site request forgery.
